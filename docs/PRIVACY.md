# WRSD privacy policy

_Last updated: 2026-10-22_

WRSD runs entirely on your PC. It makes no network connections: no telemetry, no update check, nothing is uploaded. It reads the Windows registry to build snapshots, which are stored locally (`Documents\WRSD\Snapshots` and any file you choose); settings are stored in `%APPDATA%\WRSD`. The only thing that can leave your PC is when you ask Settings & Rules to install the .NET runtime for `wrsd-cli.exe`: that runs `winget` or opens Microsoft's download page.

There is no account, no licence key, no analytics and no crash reporting. Logs stay on your machine in `%APPDATA%\WRSD and Documents\WRSD`.
